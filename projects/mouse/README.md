# thock/mouse

A web configurator for the Pulsar X2 CrazyLight Mini (React, WebHID). DPI stages, polling rate, sensor,
buttons, macros, lighting and power settings — see `CLAUDE.md` and `PROTOCOL.md`.

```bash
pnpm install
pnpm dev:mouse
```

Mounted by the root `@thock/web` app (no standalone dev server of its own) — open in Chrome or Edge;
`pnpm dev:mouse` opens straight to the demo mouse (`/?mock=mouse`).
